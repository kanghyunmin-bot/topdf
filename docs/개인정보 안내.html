개인정보 안내

작성일: 2026-10-02 · 적용 대상: TopDF 1.0.0-rc.2

처리하는 정보

사용자가 선택한 파일의 경로와 내용은 로컬에서 변환하기 위해 읽습니다. 계정, 광고 식별자, 사용 분석, 자체 오류 전송 기능은 없습니다. 문서를 외부 API에 업로드하지 않습니다.

임시 저장

변환 과정에서 운영체제의 앱 전용 임시 폴더에 원본의 복사본, 엔진 설정 및 중간 PDF를 만듭니다. 정상 종료·실패·취소 시 해당 작업 폴더를 제거합니다. 앱 강제 종료·충돌·전원 중단 시 잔여 파일이 남을 수 있으며, 보안 삭제를 보장하지 않습니다. 사용자가 저장한 PDF와 macOS·문서 앱이 관리하는 최근 항목·운영체제 로그는 별도로 유지될 수 있습니다.

네트워크와 선택 기능

문서 변환에는 서버·외부 API·로그인이 필요하지 않으며, 필요한 엔진이 설치 파일에 포함됩니다. macOS는 내장 엔진의 IP 네트워크 통신을 실행 시 차단하고, Android는 INTERNET 권한을 선언하지 않습니다. Windows는 매크로와 외부 링크의 자동 업데이트를 제한하며 방화벽으로 엔진의 외부 통신을 막은 검증 환경에서도 변환을 확인했습니다. Pages·Keynote·Numbers를 선택한 경우 설치된 Apple 앱을 호출하며 해당 앱의 iCloud 및 개인정보 설정을 따릅니다. 도움말의 외부 라이선스·소스 링크를 누르면 브라우저가 해당 사이트에 접속합니다.

운영자와 지원

운영·유지보수: kanghyunmin-bot. 문의와 오류 제보는 TopDF GitHub Issues에서 받습니다. GitHub에서 작성한 문의는 GitHub의 개인정보 정책과 공개 설정을 따릅니다. 앱이 문서나 오류 정보를 자동으로 이슈에 전송하지 않습니다.

사전 릴리스 안내

macOS는 Developer ID 서명·Apple 공증 전, Windows는 배포자 인증서 서명 전 사전 릴리스입니다. Android APK는 사전 릴리스 키로 서명합니다. 앱 스토어에 등록된 버전은 아닙니다.
