개인정보 안내

작성일: 2026-10-01 · 적용 대상: PDF로 변환 1.0.0-rc.1

처리하는 정보

사용자가 선택한 파일의 경로와 내용은 로컬에서 변환하기 위해 읽습니다. 계정, 광고 식별자, 사용 분석, 자체 오류 전송 기능은 없습니다. 문서를 외부 API에 업로드하지 않습니다.

임시 저장

변환 과정에서 macOS 임시 폴더에 원본의 복사본, 엔진 설정 및 중간 PDF를 만듭니다. 정상 종료·실패·취소 시 해당 작업 폴더를 제거합니다. 앱 강제 종료·충돌·전원 중단 시 잔여 파일이 남을 수 있으며, 보안 삭제를 보장하지 않습니다. 사용자가 저장한 PDF와 macOS·문서 앱이 관리하는 최근 항목·운영체제 로그는 별도로 유지될 수 있습니다.

네트워크와 선택 기능

내장 LibreOffice·한글 엔진의 네트워크 통신은 프로세스 실행 시 차단합니다. Pages·Keynote·Numbers를 선택한 경우 설치된 Apple 앱을 호출하며 해당 앱의 iCloud 및 개인정보 설정을 따릅니다. 도움말의 외부 라이선스·소스 링크를 누르면 브라우저가 해당 사이트에 접속합니다.

이 버전은 공개 출시 전 RC입니다. 공개 배포 시 운영자의 이름·연락처와 실제 운영 조건을 반영해 이 안내를 확정해야 합니다. App Store 제출 시에는 별도의 개인정보 정책 URL과 실제 수집 여부에 맞는 공개 항목을 작성해야 합니다.
