PDF로 변환

문서와 이미지를 Mac에서 PDF로 변환합니다. 버전 1.0.0-rc.1 · Apple Silicon · macOS 13 이상.

설치와 사용

  1. 앱을 응용 프로그램 또는 개인 Applications 폴더로 복사합니다.
  2. 앱을 한 번 실행합니다. 현재 사용자의 Finder에 ‘PDF화…’ 메뉴를 설치합니다. 관리자 권한은 필요 없습니다.
  3. Finder에서 파일을 우클릭해 PDF화…를 선택합니다. 설정에 따라 서비스 하위 메뉴에 표시될 수 있습니다.
  4. 미리보기에서 시작·끝 페이지, 원본 크기 유지 또는 A4 가로·세로 맞춤을 선택합니다. ‘미리보기 적용’으로 결과를 확인합니다.
  5. ‘PDF 저장’을 누릅니다. 기본적으로 원본 옆에 저장하며 기존 파일이 있으면 번호를 붙입니다. ‘원본 파일 옆에 저장’을 해제하면 저장 위치를 고를 수 있습니다.

여러 파일을 선택하면 하나씩 확인하고 저장합니다. 가로·세로 맞춤은 원본 페이지를 A4에 축소·확대해 담습니다. 원문을 다시 줄바꿈하거나 표를 재배치하지 않습니다. 실제 인쇄가 필요하면 ‘macOS 인쇄창…’을 사용합니다.

지원 범위

종류처리 방식
DOC/DOCX, PPT/PPTX, XLS/XLSX, ODF, RTF, CSV, TXT, HTML, EPUB 등내장 LibreOffice 26.2.6.3. 형식별 기능과 복잡한 서식은 원본과 차이가 날 수 있습니다.
HWP 5.0 / HWPX내장 hwp-cli 1.3.1. 실험적 지원. 수식은 근사 처리되며 차트·OLE는 지원되지 않습니다. 정확한 서식이 필요한 문서는 원본과 비교하세요.
PDF페이지 선택과 A4 맞춤. 암호 잠금·인쇄 제한이 있는 파일은 처리하지 않습니다. 출력물은 새 문서이며 원본의 서명·양식·첨부파일 보존을 보장하지 않습니다.
PNG, JPEG, TIFF, HEIC, BMP, GIFmacOS 이미지 엔진. TIFF는 모든 페이지, GIF와 HEIC는 첫 이미지를 사용합니다.
Pages / Keynote / Numbers별도로 설치된 해당 Apple 앱이 필요합니다. 최초 사용 시 앱 제어 허용을 요청할 수 있습니다.

한 파일 512MB, 출력 2,000페이지 이내. 문서 엔진 변환은 최대 180초입니다. 사용 가능한 원래 글꼴을 유지합니다. DOCX·XLSX·PPTX·ODF 및 HWP·HWPX에서 없는 글꼴은 가능한 나눔고딕으로 대체합니다. 구형 Office 형식과 특수 기호는 엔진의 대체 정책이 적용될 수 있습니다. 글꼴이 바뀌면 줄바꿈·페이지 수가 달라질 수 있습니다. 사용 중인 글꼴의 PDF 임베딩 권한은 글꼴 라이선스를 확인하세요.

문서와 개인정보

우리 앱은 계정·분석·문서 업로드·외부 변환 API를 사용하지 않습니다. 내장 변환 엔진은 네트워크 접근을 차단해 실행하고 LibreOffice 매크로를 비활성화합니다. HTML의 외부 이미지나 연결된 데이터는 읽히지 않을 수 있습니다. Apple 앱 경로는 해당 앱의 개인정보 설정을 따릅니다. 자세한 내용은 개인정보 안내를 확인하세요.

라이선스와 소스

TopDF 자체 코드는 MIT License로 제공하며, 포함된 오픈소스 엔진은 각 라이선스를 따릅니다. 개발자 계정·Word·한글 라이선스는 기본 변환에 필요하지 않습니다. 제3자 라이선스 및 소스 안내. LibreOffice, Microsoft, Apple, 한글과컴퓨터의 공식 제품이나 보증을 의미하지 않습니다.

제거

앱 종료 후 앱을 휴지통으로 이동합니다. Finder의 ‘이동 → 폴더로 이동’에서 ~/Library/Services를 열고 PDF화.workflow를 휴지통으로 이동하면 우클릭 메뉴도 제거됩니다. 생성한 PDF는 삭제되지 않습니다.

배포 후보 상태

이 빌드는 공개 사전 릴리스 RC입니다. Developer ID 서명과 Apple 공증이 완료되기 전에는 일반 사용자에게 정식 배포하지 마세요. 모든 형식의 완벽한 변환을 보장하지 않습니다.
